📐 SAAA 演算法規格與四捨五入核心 (0.00 標準)

設計完全遵循 SAAA 官方 R 語言原始腳本 (114M3+1A.R / 35_ctt.R) 演算法

1. 純整數 BigInt 算術四捨五入 (Pure Integer Round-Half-Up 至 0.00)
傳統 JavaScript 浮點運算常因 IEEE 754 二進位微差產生「0.605 變成 0.60」或「0.435 變成 0.43」的誤差。本系統採用純整數公式：
(2 * 100 * |k| + |n|) // (2 * |n|)，搭配 BigInt 與正負號嚴格保護，確保所有通過率、難度、鑑別度與選答率 100% 精準對齊 R 語言標準規範。


2. 精熟等級三級劃分規則 (精熟 / 基礎 / 待加強)
• 精熟 (Mastery)：答對題數 ≥ 手動輸入之精熟門檻題數。
• 基礎 (Basic)：答對題數 ≥ 手動輸入之基礎門檻題數，且小於精熟門檻。
• 待加強 (Needs Improvement)：答對題數 < 基礎門檻題數。
在試題分析中提供 6 組選答率矩陣（全體、精熟、基礎、待加強、高分組、低分組）；在成績計算中提供【扣除特殊生】與【含特殊生】併列呈現的等級描述總表。未輸入門檻時，系統純粹分析試題與總分，安全略過等級判定。


3. Kelley 27% 鐵律分群與動態 midXX 標籤
高低分組嚴格取 Kelley 經典 27% 極端組切點，中分組比例由公式 1.0 - hn_ratio - 0.27 - 0.01 動態決定，組名精確對齊 R 語言輸出（如 mid67, mid69, mid70）。
